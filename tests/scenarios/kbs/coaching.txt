Vidya Path Academy, Kota

About us: Vidya Path Academy coaches students for JEE Main, JEE Advanced and NEET in Kota, Rajasthan, since 2014.

Courses: two-year classroom programme for class 11 students, one-year programme for class 12 students, and a one-year repeater batch (dropper batch) for JEE and NEET. Batches start in April and July.

Free demo class: every new student can attend a free demo class before admission. Parents can attend the demo class with the student.

Facilities: AC classrooms, doubt-clearing sessions every evening, weekly tests, separate hostels for boys and girls near the academy.

Scholarship: up to 50% scholarship through the Vidya Path Scholarship Test (VPST).

Fees: the counsellor shares the fee structure after the scholarship test.

Address: Plot 21, Indra Vihar, Talwandi, Kota, Rajasthan 324005.
